## Project Overview
This project presents the design and development of a cost-effective feeding machine intended for robotic applications. The system is designed to reliably feed small mechanical components to a robotic pick-and-place system using a simple, modular, and manufacturable design approach.

The design was developed as part of a thesis project in Mechanical Engineering and Production Technology at Häme University of Applied Sciences (HAMK).
